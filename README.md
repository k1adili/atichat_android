# AtiChat برای اندروید

نسخهٔ اندروید پیام‌رسان آفلاین **AtiChat** که با نسخهٔ ویندوز (پایتون/PyQt6) روی یک شبکهٔ محلی با هم کار می‌کند.
ساختهٔ کیوان عدیلی.

## سازگاری با نسخهٔ ویندوز

پروتکل دقیقاً همان نسخهٔ ویندوز است:

- **UDP ‏37020**: اعلان حضور (هر ۳ ثانیه)، درخواست حضور، چت عمومی، نشانگر نوشتن
- **TLS/TCP ‏37021**: پیام خصوصی و فایل (قاب JSON با طول ۴ بایتی + بایت‌های فایل + بایت تأیید `0x06`)
- گواهی خودامضای EC P-256 و pin کردن اثرانگشت SHA-256 که از راه UDP اعلام می‌شود
- حداکثر ۱۰۰ مگابایت برای هر فایل، ۱۲٬۰۰۰ نویسه برای هر پیام، آواتار JPEG ‏۴۸×۴۸ با حداکثر ۱۶٬۰۰۰ نویسهٔ base64

هستهٔ شبکه (`core/LanNode.kt`) بدون وابستگی به اندروید نوشته شده و روی JVM مقابل `network.py` ویندوز آزمایش شده است
(کشف همتا، پیام خصوصی و عمومی، فایل در هر دو جهت، رد‌شدن اثرانگشت نادرست، تحمل ورودی خراب).

## قابلیت‌ها

- گفتگوی عمومی و خصوصی، ارسال فایل با متن همراه، حباب‌های سبز، راست‌چین/چپ‌چین خودکار
- فهرست کاربران برخط، مخاطبین آفلاین با تاریخچه، شمارندهٔ پیام خوانده‌نشده، اعلان
- سرویس پیش‌زمینه تا در پس‌زمینه هم برخط بمانید (دکمهٔ «خروج» در اعلان یا تنظیمات)
- تاریخ شمسی، فونت وزیرمتن، RTL کامل، حالت تیره و روشن
- پشتیبان‌گیری: Auto Backup برای پایگاه‌داده + «ذخیره/بازیابی پشتیبان» JSON در تنظیمات

## ساخت

با هر push به `main`، GitHub Actions آزمون‌ها را اجرا می‌کند و `app-debug.apk` را در بخش Artifacts می‌گذارد.
کلید امضا (`app/k1-personal.jks`) ثابت است تا هر ساخت جدید روی ساخت قبلی نصب شود. این کلید فقط برای نصب شخصی است.

ساخت محلی (Android Studio یا Gradle 8.9 و JDK 17):

```
gradle :app:assembleDebug
```

## نکتهٔ مهم دربارهٔ ویندوز (SNI)

نسخهٔ ویندوز هنگام اتصال TLS نام `K1chat LAN peer` (با فاصله) را به‌عنوان SNI می‌فرستد؛ این نام معتبر نیست و بعضی پیاده‌سازی‌های TLS
(مثل JDK) آن را رد می‌کنند. برای اطمینان، در `network.py` خط زیر را

```python
raw_socket, server_hostname="K1chat LAN peer"
```

به این تغییر دهید (فقط رشته عوض می‌شود، چون اعتبارسنجی نام انجام نمی‌شود):

```python
raw_socket, server_hostname="k1chat-lan-peer"
```

## ساختار

```
app/src/main/java/com/k1adili/atichat/
├── core/      # پروتکل بدون وابستگی به اندروید: Json, Jalali, Protocol, LanNode
├── data/      # Room، ChatEngine، BackupManager
├── service/   # ChatService (پیش‌زمینه) و اعلان‌ها
├── ui/        # Compose: تم، اجزا، صفحه‌ها
└── util/      # CertStore (گواهی TLS)، آواتار، فایل‌ها
```
